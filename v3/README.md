# Version 3: LoRaWAN & Solar Power

The third version transforms the station into a fully autonomous and long-range **Industrial IoT** node.

## Advanced Features
- **Microcontroller:** Heltec LoRa 32 v2 (ESP32).
- **Communication:** **LoRa** radio (868MHz) to overcome Wi-Fi range limitations in open fields.
- **Industrial Sensing:** Integration of a leaf wetness sensor via **RS485** bus.
- **Power System:** Solar power with an **MPPT** charge controller, 12V battery, and a DC-DC converter.

## Resources
- `code/`: C++ firmware for the TX (field) and RX (gateway) modules.
- `EasyEDA_Files/`: Custom design for the Heltec module.
- `img/`: Power system diagrams and photos of the final setup.
