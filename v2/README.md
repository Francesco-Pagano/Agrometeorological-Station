# Version 2: Miniaturization (Raspberry Pi Zero W)

The goal of this version was to reduce power consumption and the physical footprint of the device, preparing the system for a real-world outdoor installation.

## Upgrades
- **Hardware:** Switch to the **Raspberry Pi Zero W**.
- **Connectivity:** Introduction of standard **RJ11** connectors for plug-and-play integration with commercial anemometers and rain gauges.
- **Protection:** Housed in a waterproof junction box for outdoor operation.

## Folder Structure
- `code/`: Software optimized for the Pi Zero's low power consumption.
- `EasyEDA_Files/`: PCB design files.
- `img/`: Photos of the installation.
