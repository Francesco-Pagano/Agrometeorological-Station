# Version 4: Stand-Alone Custom PCB (WIP)

This version (currently under development) represents the maturation of the project into a finished hardware product, eliminating the need for external development boards.

## Objectives
- **Total Integration:** The **ESP8266 (ESP-12F)** SoC is integrated directly onto the main PCB.
- **Practicality:** **USB Type-C** input for power and a UART header for flashing.
- **Scalability:** Reduction of costs and mechanical assembly complexity.

## Documentation
- `EasyEDA_Files/`: Schematic and layout of the stand-alone PCB.
- `img/`: 3D render of the final "AuroProject" design.
- `Schematic_ESP8266_WS.pdf`: Electrical schematic currently under review.
